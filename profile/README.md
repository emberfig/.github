# Emberfig

**Apps, rebuilt properly.**

We find Android apps people rely on and quietly put up with, read what is wrong
with them, then build the version that answers it. Every app is free, works
without an account, and is paid for by advertising inside it.

Two developers, in Nigeria.

### What we have shipped

| | |
|---|---|
| **[StudyPomo](https://play.google.com/store/apps/details?id=com.everythingabuad.studypomo)** | A Pomodoro timer that keeps counting when the screen goes off. Live on Google Play since 9 August 2026. |
| **Ponderanda** | One arithmetic ladder a day, for adults who find arithmetic stressful. Built, not yet released. |

### Why anything is here at all

Free ad-supported Android apps have earned a reputation for harvesting data, and
the only useful answer to that is evidence rather than reassurance. So the things
we can show, we show.

[emberfig.com](https://emberfig.com) ships no JavaScript beyond a single inline
theme script, loads nothing from another company's server, and says exactly what
its apps collect and why. Publishing the source is the part that makes those
checkable instead of merely stated.

### We write up what breaks

Not the tidy version. The [rebuild notes](https://emberfig.com/notes/) cover the
release build that crashed because R8 removed a class reached only by reflection,
the notification sounds that resource shrinking deleted, and the foreground
service that Transsion firmware kills outright whatever you do about it.

Every post names what it is based on, at the top, before the argument starts.
