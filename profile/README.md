# Emberfig

**Apps, rebuilt properly.**

We find apps people rely on and quietly put up with, read what is wrong with
them, then build the version that answers it: on Android, on the web or on
Windows, wherever the problem is. Every app we publish is free to use and needs
no account with us. Advertising pays for the phone and web apps; Herewise is
free software, and departments that ask us to set it up pay for that work.

Two developers, in Nigeria.

### Why anything is here at all

Free ad-supported Android apps have earned a reputation for harvesting data, and
the only useful answer to that is evidence rather than reassurance. So the things
we can show, we show.

[emberfig.com](https://emberfig.com) runs one script of its own, inline, which
remembers whether you picked the light or the dark theme. The one thing it loads
from another company's server is Cloudflare Web Analytics, which counts visits
without cookies, and the [privacy page](https://emberfig.com/privacy/) says so.
None of that needs taking on trust: a browser's developer tools list every script
a page runs and every server it contacts.

### We write up what breaks

Not the tidy version. The [rebuild notes](https://emberfig.com/notes/) cover the
release build that crashed because R8 removed a class reached only by reflection,
the notification sounds that resource shrinking deleted, and the foreground
service that Transsion firmware kills outright whatever you do about it.

Every post names what it is based on, at the top, before the argument starts.
